# New Repo

>_ git init
>_ git add .
>_ git commit -m "Initialize repository"
>_ git remote add origin main https://github.com/USERNAME/my-project.git
>_ git remote -v (To check it was added)
>_ git branch -M main
>_ git push -u origin main
